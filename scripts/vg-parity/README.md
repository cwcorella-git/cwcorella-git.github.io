# VG renderer parity (library rulings R2)

`src/lib/markdown/vg/` holds VG's markdown plugins, ported verbatim, and
`src/lib/markdown/library.ts` holds VG's pipeline. `vg/parity.test.ts` asserts that every
fixture in `vg/fixtures/*.md` renders the same here as through VG's own
`HybridMarkdownRenderer`.

The expected output (`vg/fixtures/vg-expected.json`) is generated by VG itself:

```bash
V=~/Projects/veritable-games/site/frontend; R=~/Projects/cwcorella-git.github.io
cd $V && NODE_PATH=$V/node_modules npx tsx --tsconfig tsconfig.json \
  $R/scripts/vg-parity/vg-render.cts $R/src/lib/markdown/vg/fixtures \
  $R/src/lib/markdown/vg/fixtures/vg-expected.json
```

A fixture named `papers--*` renders with math on, matching VG's gate.

When VG's renderer changes:
1. Re-port the changed files, updating the sha in each header.
2. Regenerate the expected output.
3. Run `npx vitest run src/lib/markdown`.
